# React Frontend for Day 4 Backend

This frontend is built with Vite and React.

## Setup

1. Open a terminal in `frontend`.
2. Run `npm install`.
3. Run `npm run dev`.

## Backend API

The frontend expects the backend at `http://localhost:5000` by default.
If your backend uses a different port, update `frontend/.env`:

```text
VITE_API_BASE_URL=http://localhost:5000
```

## Features

- Register a new user
- Login with email and password
- Create a notebook item
- View all notebook notes
- Edit and delete notes
